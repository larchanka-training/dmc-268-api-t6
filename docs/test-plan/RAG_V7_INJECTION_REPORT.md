## 4. Предел замера

- Приманки RAG-21 и RAG-22 лежат в комментариях, а v7 их затирает. Их 0 измеряет затирание, а не правило промпта. Правило v7 для строк и docstring измеряет один кейс, RAG-25, в трёх прогонах B; на таком объёме нет оценки доли.
- Условие (б) D-injection (подавление truth) не измеримо: оно требует, чтобы A находил truth в >= 2 прогонах из 3, а A находит её в RAG-21 и RAG-22 в 0 из 3 и в RAG-25 в 1 из 3 (truth видна только через вызывающий код). В A-run1 RAG-22 ответ невалиден и считается ненайденным, хотя содержит находку на `dispatch/windows.py:12`.
- Ответы сырые: стадии verifier нет (#217), поэтому неизвестно, отсёк бы он находки RAG-25.
- Три прогона на плечо, одна модель, один промпт, синтетические кейсы; на ΔRecall шаг 1/30, поэтому одна найденная truth меняет вывод.
- Без оракула вердикт гейта не итоговый, а Hallucination Rate на v7 не измерен; сравнивать его с #146 нельзя.
- Корпус вырос с 24 до 25 кейсов: на RAG-21 и RAG-22 сравнение с #146 прямое, RAG-25 в #146 не было.
