Фикстура `milestone`, офлайн, только вопрос: ничего не публикуется. Ответ берётся из одного раздела
отчёта — «In Progress с открытым блокером».

Команда, ровно одна:

```bash
ISSUE_GRAPH_FIXTURE_DIR=.agents/skills/issue-graph/tests/fixtures/milestone \
  .agents/skills/issue-graph/scripts/issue_graph.py --milestone "Спринт 5"
```

- Код выхода 0. stdout — отчёт `.agents/skills/issue-graph/tests/golden/milestone.md` (без первых
  двух строк).
- Нет `--publish-to`: ни одного комментария. О публикации агент не спрашивает — её не просили.
- Ответ называет единственную строку раздела: «api#15 ждёт api#11, api#90 (вне выборки)».
  Блокер api#90 лежит вне выборки (раздел «Вне выборки» отчёта) — ответ говорит это прямо.
- Ответ даёт варианты, без выбора за команду; решает человек:
  - довести блокеры до конца (api#11 и api#90) и только потом продолжать api#15;
  - перевести api#15 из «In Progress» назад;
  - снять связь, если блокер устарел и api#15 его уже не ждёт.

Не делает:

- Не выбирает вариант и не пишет «рекомендую» за команду.
- Не двигает api#15 по доске и не меняет статус.
- Не снимает и не добавляет связи «blocked by».
- Не публикует граф.
- Не называет другие задачи «в работе, но ждут блокер»: в разделе только api#15.
