# Style

## Product vocabulary

Identifiers follow the product glossary: the paying customer is a `Workspace`,
never an `Org` or a `Team`. Report a new identifier with `org` or `team` in its
name as a readability problem.

## Modules

Feature modules use named exports, not default exports.
