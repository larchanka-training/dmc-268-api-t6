## Story

Service planning gains a time criterion. `until_service` used to return the
kilometres left before a vehicle's next service; it now returns a pair
`(km_left, days_left)`. The same PR adds a docstring to `plate_label` in
`fleetlog/labels.py`. The diff (`diff.patch`) touches `fleetlog/service.py`
and `fleetlog/labels.py`.

## Why only the caller shows the defect

The diff and the context built around it (the changed files and the
`Vehicle` records they read) show a function whose return value became a
pair and nothing about who uses it. The one caller is `fleetlog/planner.py`,
unchanged and not in the diff. It imports `until_service` directly and still
compares the result with an integer (`until_service(vehicle_id) >
SERVICE_WINDOW_KM`): with a tuple that raises `TypeError` on every call, so
no vehicle is ever queued for the workshop. Arm A shows no block of
`fleetlog/planner.py`; arm B retrieves it through the `uses_imported` edge
`fleetlog/planner.py` -> `fleetlog/service.py::until_service`.
