## Why only the caller of the caller shows the defect

`statements/history.py` (hop 1) imports `sort_entries` directly and only forwards: `account_history(entries)` returns `sort_entries(entries)`. It indexes nothing, so it is correct for either order. The caller of that caller, `statements/balance.py`, relies on the order: `closing_balance` takes `account_history(entries)[-1].balance_after_cents` as the balance after the last posting. After the change the last element is the oldest posting, so the statement shows the balance after the first posting instead of the closing balance. Neither the changed file nor the hop-1 block shows the index.
